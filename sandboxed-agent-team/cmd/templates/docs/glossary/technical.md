# Technical Glossary

The project's canonical vocabulary for technical and implementation
concepts. Every term defined here has:

- A **canonical form** used in architecture discussions, code
  comments, and technical documentation.
- An **anchor** (the heading) so technical docs can link to it
  inline via Markdown links.
- A **definition** that distinguishes it from neighboring terms,
  including how it maps to the business concept it realizes (if
  applicable).
- An optional **slang variants** list — informal or alternative
  names in common use, mapped to the canonical form.

The Architect curates and commits this file on `pattern/<slug>`
branches. Terms are proposed during requirement pre-review and task
kickoff; approved by the human before the entry is committed.

Terms may overlap with `docs/glossary/business.md` when a concept
exists at both levels — each file carries the definition appropriate
to its audience.
